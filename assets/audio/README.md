# Audio local

Los efectos de batalla se incluyen localmente para que el juego no dependa de una URL externa.

- `melee-metal-1.mp3` y `rout-cry.mp3`: impactos metálicos, priorizados en la mezcla.
- `wound-*.mp3`: tres ecualizaciones locales de `melee-metal-2.mp3`; voces de herida poco frecuentes y a bajo volumen.
- `arrow-shot.mp3`: flechas, -20% frente a la mezcla anterior.
- `battle-cry.mp3`: grito de batalla, +50%.
- `battle-ambience.mp3`: ambiente sin modificación de volumen.
- `cavalry.mp3`: sólo se reproduce cuando golpea una unidad de caballería.
